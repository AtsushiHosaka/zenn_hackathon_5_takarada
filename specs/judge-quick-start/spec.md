# 写真なしで始める審査用導線

根拠: 2026-10-12 のユーザー依頼。Google Docs URL は docs/project.md で未設定のため未確認。以下はDocs未反映の変更。

## 受け入れ条件

- ログイン後の既定遷移 /rooms/new では自分の部屋の入力フォームを最初から表示する。「始め方を選び直す」から「すぐ試す」も選べる。
- 入力フォームの「既存のテンプレートを使う」を開くと、すべてのテンプレートの部屋画像・名前・畳数・家具数を表示し、画像付きカードから選べる。画像は既存3Dの撮影・キャッシュ機構を再利用し、1部屋ずつ生成する。準備中・表示失敗を明記し、画像がなくても選択可能。
- すぐ試すは写真・広さの入力を省き、6畳の家具付きテンプレートから自分の部屋を作り3D画面へ進む。
- 希望文「水色の初音ミク推し活ルームにしたい」と初音ミクテーマを初期選択し、既存のコーディネート生成・商品表示へ進める。勝手に生成は開始しない。
- 初期テンプレートは保存済みのあとに並び、削除・編集の対象にしない。コピーした部屋は編集できる。
- 写真からの解析経路を残す。記事には2つの入口と写真解析の説明、動画には写真からの流れを示す指示を残す。

## 判断・制約

実装開始時のブランチには組み込みテンプレートがなかったが、最新mainに3種類が追加されていたため、競合解消時に既存の正方形に近い6畳テンプレートへ統合した。ベッド・デスク・本棚の配置を再利用する。
サンプル写真はdummy用SVGであり、実写真の解析用サンプルではない。実API用写真の代用にはしない。
商品提案はcoordination対応のAPI接続を必要とする。対応しない接続ではクイック開始を無効化し、理由を表示する。
1〜2分は案内上の目安。実APIの応答時間は未測定。
