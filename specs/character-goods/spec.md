# 推し活キャラクターグッズの3Dモデルと自然言語検索

2026-10-10のユーザー依頼に基づく。初音ミク、VTuber、サンリオのアクスタ・タペストリー・ぬいぐるみなどを部屋に置けるようにし、「ミクのアクスタ」のような自然言語だけで検索できるようにする。Google DocsのURLは`docs/project.md`に未設定のため、Docsは未確認。

## 権利の扱い

ユーザーは、本アプリが個人運営・非商用であると確認した（2026-10-10）。調査した規約の要点と判断は次のとおり。

- ピアプロ（初音ミクほか）: 個人による無償・非商用の3DCGモデル配布はガイドラインで認められる。配布時に、利用者がガイドラインに従う必要がある旨を明記する。宣伝・広告への利用、対価を得る利用、法人による利用は不可。
- ホロライブ（カバー）、にじさんじ（ANYCOLOR）: 個人の趣味の範囲の二次創作は可。公式と誤認させない。法人の利用は対象外。
- サンリオ: 不特定多数が見られる場所での利用を避けるよう求めているため、キャラクターの造形は作らない。辞書と検索、商品情報の表示だけに使う。
- ECの商品画像を3Dモデルのテクスチャに使わない。楽天・Yahoo!の画像CDNはCORSを許可せず、楽天の規約は画像の改変を禁じる。商品画像は従来どおり、加工せずサムネイルとして表示する。

収益化、広告、アフィリエイト、法人による運営を始める場合は、キャラクターモデルを無効化し、権利者との契約を確認する。

## 作るもの

1. グッズのテンプレート（キャラクターなし）: アクスタS/M/L・BIGアクスタ、B2/B1タペストリー、ぬいぐるみの素体、ダイカット・丸クッション、缶バッジ、ラバーマット、ブランケット、アクリルパネル。印刷面は素材名`print`。
2. キャラクターモデル: わざと粗いローポリで、色と髪形などの特徴だけでキャラクターが分かる程度にする。公式イラストを写さず、独自に作る。初音ミクから始め、確認後にピアプロの他キャラクター、ホロライブ、にじさんじへ広げる。
3. キャラクター辞書: `backend/config/characters.json`。フランチャイズ（ライセンス、クレジット、注意書き、造形の可否）、キャラクター（名前、別名と曖昧さ、所属、活動状況、色）、グッズ種別（同義語）を持つ。

## 台帳とAPIの契約

台帳`backend/db/furniture_models.json`のモデルに、次の任意フィールドを足す。既存の家具は省略でき、省略時は空として扱う。

| フィールド | 型 | 意味 |
| --- | --- | --- |
| `goods_type` | string または null | `characters.json`の`goods_types[].id`。家具はnull |
| `characters` | string[] | `characters.json`の`characters[].id`。キャラクターがないモデルは`[]` |
| `search_terms` | string[] | 検索で一致させる追加の語 |

- 取り込み時に、`goods_type`と`characters`が辞書に存在すること、`likeness_allowed=false`のフランチャイズのキャラクターを持つモデルがないことを検証する。
- DBの`furniture_models`に`goods_type`（null可）、`characters`（jsonb、既定`[]`）、`search_terms`（jsonb、既定`[]`）を足す。
- 家具モデルAPIは上記に加え、キャラクターのフランチャイズから導いた`credits`（`[{franchise, credit, notice, license_url}]`）を返す。

家具検索API（`POST /api/v1/furniture_searches`）の応答に次を足す。

- `interpretation`: `{ characters: [{id, name, franchise}], franchises: [{id, name}], goods_types: [{id, name}], source: "dictionary" | "llm" | "none" }`
- `models`: 解釈に合う台帳モデル。家具モデルAPIと同じ形
- `products[].product_metadata.characters`: 商品名で確認できたキャラクターID

グッズ検索では、台帳のモデルはECに依存しないため、Gemini未設定やEC検索の失敗時も`models`を返す（`products`は空、失敗時は`failures`=1）。家具検索の挙動は変えない。

## 検索の手順

1. 検索語をNFKC正規化し、大文字・小文字とひらがな・カタカナの違いを吸収する。
2. 辞書で解釈する。別名は最長一致で、`ambiguous=true`の別名は、グッズ種別の同義語・フランチャイズの別名・曖昧でない別名のいずれかが同じ検索語にある場合だけ一致させる（例:「プリン」単独、「シナモン色のソファ」「ミクロファイバー」はキャラクターにしない）。
3. 辞書で解釈できない語が残り、キャラクターかグッズ種別の手掛かりがありそうな場合だけGeminiで解釈する。出力は辞書のIDに限定する。
4. キャラクター、フランチャイズ、または`standalone=true`のグッズ種別（アクスタ、缶バッジなど）があれば、グッズ検索として扱う。クッション、タペストリー、ポスターなど一般のインテリアと重なる種別は、キャラクターかフランチャイズの語がある場合だけ使う。台帳モデルを`models`に返し、ECには正式名とグッズ種別名で検索する（例: 初音ミク アクリルスタンド）。どちらもなければ、従来の家具検索をそのまま使う。
5. EC商品は、商品名に正式名か曖昧でない別名がある場合だけキャラクター付きとして返す。順位は、キャラクター一致、グッズ種別一致、価格の順。

家具（`goods_type`がnull）にキャラクターを付けない。

## 未確認・制約

- 主要なグッズ店は取得先に加えていない（2026-10-10確認）。ECはYahoo!ショッピングなど既存の店舗だけで探す。
  - ホロライブ公式ショップ（Shopify）: 商品ページにJSON-LDのProductがなく、HTMLは約1.2MBで、税込の表記もない。複数キャラクターを1商品のバリエーションにまとめるため、商品名でキャラクターを確認できない。
  - にじさんじオフィシャルストア: JSON-LDはないが、HTMLは約90KBで、商品名と税込価格が本文にある。GeminiによるHTML抽出なら解析できる見込みだが、未検証のため加えていない。
  - アニメイト通販: robots.txtの`Crawl-delay: 1180`を守ると、検索時間内に取得できない。
- グッズ検索で、正式名と曖昧でない別名が商品名にないEC商品は除く。フランチャイズだけの検索では、フランチャイズ名を含む商品も残す。
- 辞書にない名前のGemini解釈は、「グッズ」「推し」などの語があるか、単独で使えるグッズ種別と辞書にないカタカナ語が並ぶ場合だけ行う。
- ピアプロ以外のキャラクターの色は公式値がない。ホロライブの色は空とする。
