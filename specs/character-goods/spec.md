# 推し活キャラクターグッズの3Dモデルと自然言語検索

2026-10-10のユーザー依頼に基づく。初音ミク、VTuber、サンリオのアクスタ・タペストリー・ぬいぐるみなどを部屋に置けるようにし、「ミクのアクスタ」のような自然言語だけで検索できるようにする。Google DocsのURLは`docs/project.md`に未設定のため、Docsは未確認。

## 権利の扱い

ユーザーは、本アプリが個人運営・非商用であると確認した（2026-10-10）。調査した規約の要点と判断は次のとおり。

- ピアプロ（初音ミクほか）: 個人による無償・非商用の3DCGモデル配布はガイドラインで認められる。配布時に、利用者がガイドラインに従う必要がある旨を明記する。宣伝・広告への利用、対価を得る利用、法人による利用は不可。
- ホロライブ（カバー）、にじさんじ（ANYCOLOR）: 個人の趣味の範囲の二次創作は可。公式と誤認させない。法人の利用は対象外。
- サンリオ: 不特定多数が見られる場所での利用を避けるよう求めているため、キャラクターの造形は作らない。辞書と検索、商品情報の表示だけに使う。
- ECの商品画像を3Dモデルのテクスチャに使わない。楽天・Yahoo!の画像CDNはCORSを許可せず、楽天の規約は画像の改変を禁じる。商品画像は従来どおり、加工せずサムネイルとして表示する。

収益化、広告、アフィリエイト、法人による運営を始める場合は、キャラクターモデルを無効化し、権利者との契約を確認する。

## 作るもの

1. グッズのテンプレート（キャラクターなし）: アクスタS/M/L・BIGアクスタ、B2/B1タペストリー、ぬいぐるみの素体、ダイカット・丸クッション、缶バッジ、ラバーマット、ブランケット、アクリルパネル。印刷面は素材名`print`。
2. キャラクターモデル: わざと粗いローポリで、色と髪形などの特徴だけでキャラクターが分かる程度にする。公式イラストを写さず、独自に作る。初音ミクから始め、確認後にピアプロの他キャラクター、ホロライブ、にじさんじへ広げる。

## データ

2026-10-10のユーザー指示で、キャラクターを辞書ファイルから DB のテーブルへ移し、家具とは中間テーブルでつなぐ形にした。

```
franchises       作品・事務所。名前・別名・ライセンス・クレジット・注意書き・造形の可否 (likeness_allowed)
  └─ characters  名前・英名・別名 (曖昧さ付き)・グループ・活動状況・色・キャラクターテーマ
       └─ character_goods  キャラクター ↔ 家具 (furnitures) の多対多
furnitures       推し活グッズは category にグッズ種別 (acrylic_stand など) を持つ
```

- `db/characters.json`（フランチャイズとキャラクター）を`rails character:import`で取り込む。JSONを正とし、載っていないものは消す。
- `db/furnitures.json`の各モデルの`characters`（キャラクターのキー）から、`rails furniture:import`が`character_goods`を作る。キャラクターは先に取り込む（デプロイ・compose・seedは`character:import`→`furniture:import`の順）。
- 造形を認めないフランチャイズ（`likeness_allowed=false`）のキャラクターは、グッズに付けられない（`CharacterGoods`の検証）。
- グッズ種別は家具の`category`。名前・同義語・単独で検索できるか（`standalone`）は`config/goods_categories.json`に持つ。キャラクターを付けた家具の`category`は、この一覧にあるものに限る。
- 既存のモデルのうち、アクリルスタンド・缶バッジディスプレイ・うちわ・ポスターは`category`がグッズ種別に変わった（`oshi_goods`・`wall_art`から）。
- 写真の家具にモデルを推測で当てるときは、キャラクターの付いた家具を使わない（`Furniture.without_characters`）。
- 検索用の追加語（旧`search_terms`）は、検索で使われていなかったため持たない。

## API

- `/api/v1/furniture_models`と、家具検索の`models`・`products`は、`characters`（キャラクターのキー）と`credits`（`[{franchise, credit, notice, license_url}]`。フランチャイズごとに1件）を返す。
- 家具検索（`POST /api/v1/furniture_searches`）は`interpretation`（`{characters, franchises, categories, source}`）と`models`（グッズの3Dモデル。最大24件）を返す。家具検索では各一覧が空で`source`は`none`。

## 検索の手順

1. 検索語をNFKC正規化し、大文字・小文字とひらがな・カタカナの違いを吸収する。
2. キャラクター・フランチャイズの別名（DB）とグッズ種別の同義語で解釈する。別名は最長一致で、曖昧な別名は、グッズ種別の同義語・フランチャイズの別名・曖昧でない別名のいずれかが同じ検索語にある場合だけ一致させる（例:「プリン」単独、「シナモン色のソファ」は、キャラクターにしない）。
3. 何も解釈できず、グッズを探していそうな検索語に限り、Geminiで辞書のIDを選ばせる。
4. キャラクター、フランチャイズ、または`standalone=true`のグッズ種別（アクスタなど）があれば、グッズ検索にする。クッションなど一般のインテリアと重なる種別は、キャラクターかフランチャイズの語がある場合だけ使う。家具の種類の絞り込みを指定した検索は、従来の家具検索にする。
5. グッズ検索の3Dモデルは、キャラクターと種別が一致、キャラクターだけ一致、キャラクターのない種別のテンプレートの順。フランチャイズだけなら、そのフランチャイズのキャラクター全員を対象にする。
6. 商品は、対象の家具に付いている detail。キャラクターを探しているときは、キャラクターの付いていない家具（一般のクッションなど）の商品は出さない。

## 未対応

- ピアプロ以外のキャラクターの色は公式値がない。ホロライブの色は空とする。
