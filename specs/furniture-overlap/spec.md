# Whole-furniture overlap outlines

Source: GitHub issue #75 read 2026-10-09. Google Docs URL is unset in docs/project.md; Docs were not checked or updated. Foundation is current #72 image goods / PR #89 plus #71 focus / PR #98, plus #78 support-contact / PR #101 (head 98f2e095). PR targets #101 branch until dependencies land.

## Behavior

- Detect intersection with a broad phase on declared item volumes: strict Y penetration and separating-axis checks on the rotated XZ footprints. Exact face/edge contacts do not collide; both affected item IDs are reported. A narrow phase checks actual rendered mesh-part bounds, avoiding empty gaps beneath desk tops and between legs. Known cover/bed_cover/rug/wall_decor/artwork/led/poster adornments are exempt because they intentionally overlay furniture or room surfaces. Joined GLBs remain conservative (their single mesh bounds include internal gaps). Changes from committed edits, drag previews and insertion previews update the same scene's warnings immediately. Before only considers its visible items.
- Render actual mesh silhouettes with Three OutlinePass: one shared mask buffer is used separately for each affected furniture object, preserving its complete outline even behind another object. Visible and hidden outlines are red; surfaces, textures and colors remain unchanged. No bounding boxes, red material fill or intersection-only coloring are used for overlap feedback.
- Removing penetration removes red contours immediately. Existing purple selection/focus, view changes, resets, drag cancellation and render lifecycle remain intact.
- Transparent outline-target allocation is lazy and bypassed for scenes without targets. The original renderer draws the scene normally; only edge alpha is overlaid in red, preserving clear color, lighting and per-material tone mapping. Resize and cleanup dispose owned passes/render targets. The same renderer/canvas/animation loop is retained; stable layout overlap detection is cached, and preview idle gating is retained. Outlines do not pulse, so reduced motion adds no animation.
- #78 records actual mesh surface contact using optional supportObjectId and captured supportSurface. Only a valid matching support footprint and elevation exempts that support pair; it does not suppress collisions with any other item. Overlap exemption uses the shared furnitureSurfaceHeight validation from #78; drag and insertion previews forward the actual picked support metadata.
- Item/procedural model groups are faithful whole-object targets. Complete GLB models are mapped using actual node extras/IDs/names, known catalog model filename, or uniquely contained mesh geometry. The catalog generator joins a model into a mesh named after its GLB filename (tools/furniture_models/lib.py/build.py). Modern scene APIs use individual model URLs; aggregate complete models are a legacy input. Ambiguous/unmapped aggregate geometry cannot provide a faithful object silhouette and is not replaced with metadata hit boxes. That coverage limit must remain explicit in the PR.
