## Decisions and acceptance

The Products/Edit panel retains exactly one subtree for its 150ms exit, then changes content and enters for 180ms. This sequential fade was accepted during integration to avoid duplicating planner hooks and local state. Closing content is inert and hidden from assistive technology immediately. Reopening cancels removal; switching again cancels the previous content timer. Reduced motion switches/removes immediately. An initially visible panel does not steal page focus. On user activation, focus follows the new heading and returns to the opening button after dismissal unless the user moved focus elsewhere. Each mode remembers its scroll position; returning to the product list does not override that position with an unchanged selection.

RoomViewer stays outside the panel transition. Panel visibility changes available canvas size once without animating dimensions; the existing right-offset transition is removed because it resized the canvas every animation frame. The mobile editor transition wrapper occupies the viewport so its translated layer preserves the upstream fixed planner overlay. Recommendation rows retain product IDs as keys; newly inserted rows enter with stagger capped at 120ms, and surviving rows move at most 48px for 180ms after filtering. Hover or selection does not remount/replay the list. Native external links activate immediately. A changed keyboard/programmatic selection scrolls only if its row is outside the visible list. Pointer hover selects without moving the list, and exiting inert panels do not auto-scroll. This also prevents the stationary pointer from undoing scroll restoration when new content appears beneath it.

Furniture, swatch, view, Before/After, undo/redo, save/download and request controls use short color, shadow and opacity feedback. Focused targets do not translate or scale. Request additions gain a browser-only UUID once, including legacy category-only records; each removed row independently exits while the remaining controls retain their identities. Removal focuses the next or previous native request select; removing the last request focuses the native Add furniture button immediately and through the outgoing row exit. The coordination repository sends category-only additions, preserving its API contract. Dimensions and pin tooltips use the shared individual translate property, preserving existing absolute positions and positioning transforms. Reference pins compare the current demo geometry directly: truthful product colors no longer accidentally disable them through the legacy purple-rug narrative check. The narrative remains separate and does not make false color claims. Renderer, snapping, drag constraints, camera controls, save success/error behavior and native CSV activation remain unchanged.
