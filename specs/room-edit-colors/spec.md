# 壁・床・家具の色編集と入力欄の整理

根拠: 2026-10-12 のユーザー依頼と追加指示。Google Docs URLは docs/project.md に未設定で未確認。以下はDocs未反映。

## 受け入れ条件

- 編集パネルから「写真から検出した家具」（説明・未検出表示・チェックリスト含む）と「AIに提案してほしい家具」を除去する。
- 壁・床・選んだ家具に、それぞれ水色・白・緑・赤・黄色のパステル5色とカラーピッカーの計6つを表示する。
- 各色は独立して変更でき、既存の3Dプレビュー・変更保存・元に戻す/やり直すを使える。
- 商品の家具色変更は既存のpreviewColorに反映し、実際の商品色と混同させない。

- 編集タブは「選んだ家具 → 部屋 → 家具を追加」の順。家具の選択リストと選択中の見出しに既存の商品番号を表示する。markerを優先し、未指定の商品は商品一覧と同じ買い足し家具の順序番号を使う。既存家具には番号を捏造しない。

## 判断

パステル色は水色 #BFE3F5、白 #FFFFFF、緑 #CDE8D1、赤 #F3C5C5、黄色 #FFF0B3。自由に選ぶを6つ目の選択肢とする。
検出自体や個別家具の商品置き換え処理は残す。入力UIだけを除去し、既定の既存家具保持を変更しない。
API契約・DB変更なし。色編集の保存は既存の利用者別ブラウザ保存を利用する。AI再生成後の壁・床の維持は今回の実装対象に含めず、既存の生成動作に従う。
