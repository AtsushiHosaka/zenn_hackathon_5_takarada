# Furniture search and retail color variants — issue #77

Source: [GitHub issue #77](https://github.com/AtsushiHosaka/zenn_hackathon_5_takarada/issues/77), read 2026-10-09. Google Docs URL is unset in docs/project.md; Docs was not checked or updated.

The editor adds a furniture search entry, an official-color filter, and selection of published color variants. Filtering uses official product color text, never preview recoloring, dominant image RGB, or an inferred title color. Missing published color remains searchable without a color filter and is excluded when a color is requested. Search reuses grounded discovery and official page verification and surfaces unavailable credentials, timeouts, empty results and partial page failures.

`POST /api/v1/furniture_searches` requires authentication and accepts query, optional category and optional color. Results are verified candidates, limited to 24. The existing selected URL import verifies the chosen variant again before it can be placed. Selecting a variant changes its own EC identity, product URL, price, image, dimensions and model matching. The selected EC ID and metadata persist through existing room save/reload and coordination inputs. Raw EC IDs remain separate from public recommendation IDs.

2026-10-09 dogfood repair, authorized by the user's followup: a recorded unrestricted `椅子` search included a mattress protector. Category-free queries previously had no deterministic result-category constraint. When a query has one recognizable category and ends with that category word (for example `椅子`, `白い椅子`, or `white chair`), constrain both discovery and verified results to that category. The explicit category selector takes precedence. Ambiguous/contextual prose such as `椅子とテーブル`, `chair cushion`, and `机に合わせる収納` retains the existing broad search rather than silently choosing a reference category. This is a conservative category rule, not full semantic relevance ranking.

The repeated live query returned eight seating products; the original mismatch is intermittent and the original protector's extracted category remains unknown. An isolated controlled mixed-candidate probe confirmed the old service admits bed/table candidates for a chair query and the repaired service excludes them. Thirteen temporary probes verified category inference, normalization, explicit selector precedence, official-color filtering and conservative fallback. Existing search request specs passed 3 examples; changed service RuboCop passed. No new tests, schema, API fields or dependencies were added. The service repair has not been deployed; live provider correctness and the original item's exact classification are not claimed. Evidence: `docs/pr-evidence/atmosphere-search/README.md`. Google Docs remain unverified because the project URL is unset.

Variants come from the official IKEA color picker or a JSON-LD ProductGroup containing the selected SKU. The IKEA picker was inspected on the official GLADOM white page on 2026-10-09: white 50337820, black 00411997, dark gray green 50578452, and light blue 90534003. Generic related links and matching names do not establish variants. Links use existing allowed retail origins/paths. URL query strings remain part of variant identity; same-page variants can supply a published SKU. The importer rejects a requested SKU when the page does not expose that selected product.

Unverified or sold-out choices cannot be added. Retailers that do not publish supported variant relationships retain ordinary search/import; the UI states when color choices could not be confirmed. This does not claim every retailer's JavaScript-only selector is supported. Dummy mode explains that real product search needs API mode; it does not present invented retail results.

No DB schema, environment variables, or existing generation contracts change. The new API and optional import `variant_id` are exposed through regenerated OpenAPI and frontend types; iOS can adopt the additive contract separately.

Existing frontend lint and production build passed; the build retains the existing large-chunk warning.
