# へやいろのWebアイコン

2026年10月4日のユーザー指定により、プロダクト名を「へやいろ」とし、丸い台座を除いた生成画像を採用する。ログイン画面の暗い背景と紫の部屋を参考にした画像を、ブラウザとホーム画面のアイコンへ反映する。

## 反映する内容

- ブラウザのタイトルとアプリ名を「へやいろ」にする。
- faviconは16・32・48pxを収録したICOと16・32pxのPNGを用意する。
- Apple用は180px、Webアプリ用は192・512pxのPNGを用意する。
- Web App Manifestの名称とアイコンを設定する。画像の端を切らないため、アイコンの用途は`any`とする。
- 元画像は`frontend/public/icons/heyairo-icon.png`に保存し、各サイズは同じ画像から縮小する。

## 根拠と範囲

Google DocsのURLは`docs/project.md`で未設定のため未確認。このチャットの名前決定、アイコンの採用とfavicon対応の依頼を暫定の根拠とする。Google Docsへは未反映。API・DB・環境変数・iOSの変更はない。ホーム画面用のメタデータを追加し、オフライン機能は追加しない。
