# Small objects on furniture (#78)

Source: GitHub issue #78, 2026-10-09. Google Docs URL is unset; Docs is unverified and these decisions have not been reflected there.

Compact objects up to 80 cm on each axis, including acrylic stands and desk lamps, snap to the actual rendered horizontal surface of shelves, desks, tables, storage, TV stands or displays when dragged onto them. Floor furniture, posters, rugs and mirrors retain their positioning rules. A full rotated rectangular footprint must fit on the support, and the object must fit below the room ceiling. Positions keep the existing 10 cm horizontal grid; vertical contact is exact and is not rounded to that grid.

Raycasting selects a rendered horizontal mesh face and validates all rotated footprint corners in mesh-local bounds; round table tops also check radius. Adding and movement preserve that exact contact height. Keyboard movement, rotation and resizing retain the height while the support footprint fits. Click-to-center additions stay on the floor instead of guessing a top from aggregate model dimensions. Dragging off a support returns compact objects to the floor. Canceling restores the original position. Existing edited-item persistence stores the vertical center and API serialization preserves its bottom coordinate. No additional canvas or render loop is created.

The optional browser-local supportObjectId identifies a ray-picked supporting furniture object. A bounded supportSurface profile captures that mesh’s world-to-local transform, local bounds, optional actual cylinder radius, contact height, and supporting furniture position/size/rotation. Drag, keyboard movement, rotation and resizing check all four corners against the same captured footprint. Rectangular imported meshes are not assumed round from category. Profiles reject nonfinite, singular, empty, inverted or oversized values; floor/manual-height moves and deleted or changed supports clear them. Existing saved support IDs without a profile safely return to the floor during the next edit; dragging onto the surface captures a new profile. Support bounds validate subsequent edits; completed room GLBs retain their existing disabled layout-edit behavior. Moving a support does not carry its contents automatically; intermediate shelves inside a single model are not separate placement targets.

Dependencies: image-goods import (#72) and furniture focus (#71). No API or DB contract changes.
