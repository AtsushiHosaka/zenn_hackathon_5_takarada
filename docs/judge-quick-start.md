# 写真なしでデモを試す

ログイン後に「写真なしですぐ試す」を選ぶと、家具付き6畳のテンプレートが開きます。「水色の初音ミク推し活ルームにしたい」という希望文と初音ミクテーマが入力済みなので、「この部屋で作成」を押し、3Dの変化と提案された商品を確認します。コーディネート対応のAPI接続が必要です。1〜2分は目安で、APIの応答時間は未測定です。

写真があれば、「自分の部屋で試す」からGeminiによる部屋の解析を体験できます。

記事ではこの2つの入口を紹介し、動画では写真アップロード → Geminiによる部屋・家具の解析 → コーディネート → Before/After → 商品一覧までの流れを必ず見せます。写真は撮影者の掲載許可を確認したものを使います。動画撮影・公開は未実施です。
